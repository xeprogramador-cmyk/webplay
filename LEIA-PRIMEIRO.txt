================================================================================
  PASSOS (só isto)
================================================================================

1) CLOUDFLARE WORKER (2–5 minutos)
   - Entra em https://dash.cloudflare.com
   - Workers & Pages → Create → Create Worker
   - Nome: webplay-proxy
   - Apaga o código de exemplo
   - Abre o ficheiro worker/worker.js e cola TUDO lá dentro
   - Deploy
   - Copia a URL que aparece, exemplo:
       https://webplay-proxy.teu-user.workers.dev

2) LIGAR O SITE AO WORKER (30 segundos)
   - Abre index.html num editor de texto
   - Procura esta linha (está perto do início do JavaScript):

       const WP_PROXY = "https://webplay-proxy.TEU-USER.workers.dev";

   - Substitui TEU-USER pela tua URL real do Worker
   - Guarda o ficheiro

3) SUBIR O SITE
   - Podes subir TODA esta pasta para:
       • GitHub + Cloudflare Pages  (recomendado)
       • Netlify / Vercel / qualquer alojamento estático
       • Ou o teu servidor normal (já não precisas de PHP)

4) (OPCIONAL MAS RECOMENDADO) CACHE KV
   - No Cloudflare: Workers → KV → Create namespace → nome: webplay-cache
   - No teu Worker → Settings → Variables → KV Namespace Bindings
   - Variable name: CACHE  |  Namespace: webplay-cache
   - Deploy de novo
   - Isto reduz muito o uso da quota da TMDB

================================================================================
  TESTAR
================================================================================
  Depois de mudar a URL no index.html, abre o site e verifica se:
  - Capas dos filmes aparecem
  - Catálogo carrega
  - Não há erros de CORS na consola do browser (F12)

  Se o Worker estiver bem, na consola de rede vais ver pedidos a:
    https://webplay-proxy....workers.dev/tmdb?path=...
    https://webplay-proxy....workers.dev/proxy?url=...
