================================================================================
  WEBPLAY — SÓ COLAR NO CLOUDFLARE
================================================================================

Fazes 3 coisas. Nada de PHP. Nada de InfinityFree.

--------------------------------------------------------------------------------
1) WORKER (proxy TMDB + SuperFlix)
--------------------------------------------------------------------------------
  1. dash.cloudflare.com → Workers & Pages → Create → Create Worker
  2. Nome: webplay-proxy
  3. Apaga o código de exemplo
  4. Abre worker/worker.js e cola TUDO
  5. Deploy
  6. Copia a URL (exemplo):
       https://webplay-proxy.abc123.workers.dev

  (Opcional) KV cache:
       Workers → KV → Create "webplay-cache"
       No Worker → Settings → Variables → KV binding name: CACHE
       Deploy outra vez

--------------------------------------------------------------------------------
2) UMA LINHA NO index.html
--------------------------------------------------------------------------------
  Abre index.html e procura:

    const WP_PROXY = "https://webplay-proxy.TEU-USER.workers.dev";

  Troca TEU-USER pela tua URL real do passo 1.
  Guarda.

--------------------------------------------------------------------------------
3) SITE NO CLOUDFLARE PAGES
--------------------------------------------------------------------------------
  Opção rápida (upload):
    Workers & Pages → Create → Pages → Upload assets
    Sobe TODOS os ficheiros desta pasta (exceto a pasta worker/ se quiseres)
    Deploy

  Opção GitHub:
    Sobe esta pasta para um repositório
    Pages → Connect to Git → Deploy (build vazio)

  Ficas com: https://algo.pages.dev

--------------------------------------------------------------------------------
O QUE CADA FICHEIRO É
--------------------------------------------------------------------------------
  index.html            → site principal (catálogo)
  index-criador.html    → botão + (criar / publicar)
  worker/worker.js      → colar no Worker
  idioma.js, etc.       → resto do site (não mexer)

  Não precisas de: tmdb-cache.php, proxy.php, InfinityFree

--------------------------------------------------------------------------------
TESTAR
--------------------------------------------------------------------------------
  Abre o link do Pages.
  Capas e géneros devem aparecer.
  O botão + abre a área de criar.

  Se algo falhar: F12 → Rede
    - pedidos a ...workers.dev/tmdb  devem ser 200
    - pedidos a ...workers.dev/proxy devem ser 200
